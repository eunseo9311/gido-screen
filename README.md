# 함께 드리는 기도

성도가 휴대폰으로 올린 기도를 담당자가 확인한 뒤, 예배당 16:9 모니터에 한 장씩 천천히 넘겨 보여 줍니다.

| 파일 | 누가 | 하는 일 |
|---|---|---|
| `/` (첫 화면) | 성도 | 기도와 이름(선택)을 적어 올립니다 |
| `/admin` | 담당자 | 올라온 기도를 고치거나 송출·숨김합니다 |
| `/screen` | 방송실 모니터 | 승인된 기도를 7초씩 한 번만 보여 줍니다. 다 나가면 안내 화면에서 새 기도를 기다립니다 |

Firebase 프로젝트 `sarang-gido-screen`(eunseosong4916@gmail.com 소유, 무료 Spark 요금제)에 연결되어 있습니다. `config.js`의 `firebaseConfig`를 `null`로 바꾸면 체험 모드(한 브라우저 안에서만 저장)로 돌아갑니다.

담당자를 추가하려면 `firestore.rules`의 이메일 목록에 넣고 `firebase deploy --only firestore:rules`로 올린 뒤, 콘솔 Authentication → 사용자에서 같은 이메일로 계정을 만드세요.

## Firebase 준비 (한 번, 약 10분)

1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됩니다)
2. 왼쪽 **Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
3. Firestore의 **규칙** 탭에 `firestore.rules` 내용을 붙여 넣고, `담당자이메일@example.com`을 실제 담당자 이메일로 바꾼 뒤 **게시**
4. **Authentication → 시작하기 → 이메일/비밀번호** 사용 설정 → **사용자** 탭에서 담당자 계정 추가
5. 프로젝트 설정(톱니바퀴) → **내 앱 → 웹 앱(</>) 추가** → 나오는 `firebaseConfig` 값을 `config.js`에 붙여 넣기
6. Authentication → 설정 → **승인된 도메인**에 `eunseo9311.github.io` 추가

`firebaseConfig` 값은 웹페이지에 공개돼도 괜찮은 값입니다. 누가 무엇을 할 수 있는지는 3번 규칙이 정합니다.

## 주일 사용 순서

1. 방송실 PC에서 `/screen`을 열고 화면을 한 번 눌러 전체화면
2. 담당자는 휴대폰이나 노트북으로 `/admin`에 로그인
3. 성도는 화면의 QR이나 주보의 QR로 `/` (첫 화면)에 접속해 기도를 올림
4. 담당자가 **송출**을 누르면 새 기도가 바로 다음 장으로 올라옴
5. 예배가 끝나면 승인 화면의 **송출 중** 탭에서 **송출 목록 비우기**

송출 화면 조작: 누르기(또는 `f`) 전체화면, `→` 다음 기도, 스페이스 멈춤. 주소 뒤에 `?sec=12`를 붙이면 넘기는 간격, `?qr=0`을 붙이면 QR을 숨깁니다.
